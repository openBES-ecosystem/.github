# Support

Welcome to the openBES-ecosystem! We're here to help you with building energy simulation research and tools.

## 📖 Getting Help

### Documentation

Start with the documentation in individual repositories:
- Each repository has a README with setup and usage instructions
- Check the wiki or docs folder if available
- Review example files and tutorials

### Common Questions

**Q: Where do I start?**
- Browse repositories at https://github.com/openBES-ecosystem
- Read the organization profile at [profile/README.md](profile/README.md)
- Review the [Contributing Guidelines](CONTRIBUTING.md)

**Q: How do I report a bug?**
- Use the Bug Report template in the relevant repository
- Provide detailed reproduction steps
- Include your environment details

**Q: How do I suggest a feature?**
- Use the Feature Request template
- Explain your use case and expected benefits
- Search existing issues first to avoid duplicates

**Q: Can I contribute research or data?**
- Yes! Use the Research Contribution template
- Share validation studies, benchmarks, or datasets
- Follow our open science principles

### Communication Channels

1. **GitHub Issues** - For bugs and feature requests
   - Use in the specific repository
   - Follow the issue templates

2. **GitHub Discussions** - For questions and ideas
   - Ask general questions
   - Share ideas and best practices
   - Connect with the community

3. **Pull Requests** - For code contributions
   - See [CONTRIBUTING.md](CONTRIBUTING.md)
   - Use the PR template

## 🐛 Reporting Bugs

1. Check if the bug has already been reported
2. Use the Bug Report template
3. Provide clear reproduction steps
4. Include error messages and logs
5. Specify your environment (OS, versions, etc.)

## 💡 Requesting Features

1. Search existing feature requests
2. Use the Feature Request template
3. Explain the problem or use case
4. Describe your proposed solution
5. Consider contributing the implementation

## 🔬 Research Support

For research-related questions:
- Review published validation studies
- Check repository documentation for methodology details
- Use the Research Contribution template to share findings
- Engage with researchers through Discussions

## 🆘 Need More Help?

If you can't find what you need:

1. **Search first**: Check README files, issues, and discussions
2. **Ask in Discussions**: Post your question with relevant context
3. **Open an issue**: If it's a specific problem with a tool
4. **Be specific**: Provide context about your building simulation needs

## 🚫 What We Cannot Support

- Consulting services for specific building projects
- Custom development for proprietary applications
- Troubleshooting non-ecosystem tools
- Issues outside the scope of early-stage simulation

## ⏱️ Response Times

As an open-source research ecosystem:
- We aim to respond to issues within 1 week
- Response times vary based on maintainer availability
- Community members often help each other
- Urgent security issues are prioritized (see [SECURITY.md](SECURITY.md))

## 🤝 Community Support

- Be respectful and follow our [Code of Conduct](CODE_OF_CONDUCT.md)

- Provide context and details
- Be patient - maintainers are volunteers
- Help others when you can
